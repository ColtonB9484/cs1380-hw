What does end - start mean when both pointers point into the same int array?

Why is *(prices + 5) undefined behovior for an array of length 5, even if it compiles?
	Because it would be the same as calling prices[5]. Since C starts arrays at index 0, this means that a 5 element array is 0 - 4, not 1 - 5. So it would go to
	the memory address where prices[5] should be and receive whatever garbage data is in there
