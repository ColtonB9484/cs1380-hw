1) fopen returns NULL on failiure. You should always check if the file opened 
	successfully before using FILE *

2) "w" writes to a new file. This can overwrite an existing file, so use it carefully
	"r" reads text from a file as input. It reads line by line

3) you should fclose on every exit path to make sure that you don't corrupt a file.

4) fgets is a better choice than fsanf for reading a line because fgets scans the 
	whole line, and puts that in string format. While fscanf will scan a line
	for a given format. For example fgets(FILE, "%d", &num); will find and scan
	an integar.

5) fwrite writes a specified number of elements to a file, while fprint f writes
	a formatted output to a file.
