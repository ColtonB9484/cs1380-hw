Valid indices for an array of length n run from which value to which value? What does C do if you read scores[n]?
	Valid indices are from 0...n-1
	If you read scores[n] C will fail to compile, since scores[n] would be out of the valid range by one value

Why does sizeof(scores) / sizeof(scores[0]) work in main on the actual array, but fail inside a function that took const int scores[]?
	It works in main because arrays become pointers when passed as an argument into a function. 

For int board[3][4], which element is board[1][2]
	It would be Row 2, Column 3
	Rows are the first element of the array so anything board[1]<-here[2], Columns are the second element in the array board[1][2]<- here

Why must a function that recieves an array also reveice the length?
	Because arrays don't store their own size. Since there is not 'end array' marker, you need to calculate the size of the array and pass the size in
	as an argument
In your 2d print loop, which index is the row and which is the column? What goes wrong if you swap them?
	The first index (board[this index][]) is the row. The second index (baord[][this index]) is the column.
	If they're swapped you could get garbage data from whatever is in the memory address at the 'next' index
