What are the base case and recursive case for you factorial?
	The base case is if(n <= 1) return 1;
	The recursive case is anytime n > 1

What goes wrong if you omit the base case?
	The program will loop indefinitly until the memory is completely filled.
	Causing a stack overflow

When might a loop be a better fit than recursion for summing an order?
	A loop might be better if the an order's length is a defined length. So n
	is always the same.

What does a function pointer store?
	The memory address of the argument

How can apply_op stay unchanged while cafe changes which price rule runs?
	Since apply_op takes in a fuction as an argument, the app can just
	run the function with the two given integar arguments. As long as there
	are two int values that are passed in and the function name, the apply_op
	will work.

Why is a hand trace usefule before you chase a recursive bug in the debugger?
	It can help show where a logical bug may be occuring. Or it can be used
	to help verify the output

Which commit message would you choose after fixing a missing base case, and why is that better than fix?
	"Add base case to recursion to stop infinite loop". This is better because
	it tells what specific part of a program was fixed, and why it needed to be
	fixed.
