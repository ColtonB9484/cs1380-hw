What are the base case and recursive case for you factorial?
	The base case is if(n <= 1) return 1;
	The recursive case is anytime n > 1

What goes wrong if you omit the base case?
	The program will loop indefinitly until the memory is completely filled.
	Causing a stack overflow

When might a loop be a better fit than recursion for summing an order?
	A loop might be better if the an order's length is a defined length. So n
	is always the same.
